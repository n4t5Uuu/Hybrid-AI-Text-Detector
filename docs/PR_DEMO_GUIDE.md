# 🚀 Demo Pull Request Guide

This is a demonstration branch (`feature/demo-pr-guide`) created to show the team how to create, review, and merge a Pull Request (PR) on GitHub.

---

## 📌 How to Create a Pull Request on GitHub

1. Push your feature branch to GitHub:
   ```bash
   git push -u origin feature/demo-pr-guide
   ```
2. Go to the GitHub repository page: `https://github.com/n4t5Uuu/Hybrid-AI-Text-Detector`
3. Click the yellow banner: **"Compare & pull request"**.
4. Set **Base Branch** to `dev` or `main`.
5. Write a clear title and description explaining your changes.
6. Click **"Create Pull Request"**.

---

## 👥 How to Review & Merge

1. Team members review the PR under the **"Files changed"** tab.
2. Click **"Approve"** if the changes look good.
3. Click **"Squash and merge"** or **"Merge pull request"**.
4. Delete the branch on GitHub after merging.
